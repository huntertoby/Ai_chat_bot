# D-37 先回話、再依回話挑表情 — 規格

> 決定：D-37（使用者：「不能 先讓他回話 然後再依照他的回話 選擇 要貼哪種貼圖嗎 這樣語音也不用 選貼圖直接出阿」）。決定紀錄 36b2b63。
> 背景：現在表情是回覆 prompt 裡放清單（`prompts.EMOJI_RULES`），模型一邊寫回話一邊塞 `:名稱:`／`[貼圖:名稱]`，`emoji_catalog.process_reply` 再換成真的表情。D-33 試過「插話判斷時一起選表情、選 react 就不開口」，沒達標、不上線。使用者補充：微笑類表情群組常拿來嘲諷（D-33）。

## 做法（開發 PM 照保守方式定）
| 項目 | 定案 | 理由 |
|---|---|---|
| 表情放哪 | **放在她自己的回話裡**（自訂表情接在文字最後；貼圖用 `stickers=` 附在同一則），跟現在一樣。不按在對方訊息上 | 不改使用者看到的樣子；按在別人訊息上是 B2 的範圍 |
| 多久配一次 | 沿用 `EmojiPacing`（剛用過的下幾則不挑），加上模型可以選「不配」。目標：有圖鑑的伺服器回話裡 10%～30% 有配（開發規格 6.14 驗收） | 不要每則都配 |
| 會不會拖慢 | 回話產生完 → 挑表情（短的一次呼叫，不帶工具）→ 一起送出。D-38：文字可以等 5～10 秒，**整則回話（含挑表情）以 10 秒為上限**；挑表情的上限用常數，依「回話已花的時間」算剩餘時間（例如剩不到 1 秒就不挑），超時或出錯就不配、照送。報告寫多花的秒數（中位數、最大）和總時間超過 10 秒的比例 | 先送再補只能另發一則貼圖或編輯訊息，會多一則訊息或出現「已編輯」，比較怪 |
| 純按表情不回話（B2） | 維持現狀，不擴大；`CHIME_EMOJI_LIST` 預設維持 0；插話判斷 prompt 不改 | 使用者：被嘴一定要開口 |

## 要做的
1. **回覆 prompt 拿掉表情清單**：`Brain.reply` 的 `emoji=` 不再把清單放進 system（`EMOJI_RULES` 不再用於回覆）。`process_reply` 保留，當安全網（模型自己寫了 `:名稱:` 還是照現在的規則處理或清掉）。人設裡「群組有自己的表情或貼圖可用時，偶爾可以拿來代替一般表情」那句看情況改寫成不鼓勵在文字裡寫表情。
2. **新的一步「挑表情」**（新函式，例如 `emoji_catalog.pick` 或 `yuki/emoji_pick.py`）：
   - 輸入：原訊息（她要回的那則，含說話者佔位名）、她的回話文字、這個伺服器圖鑑的清單（`use=true`、照現在 `prompt_block` 的挑法和數量）。
   - 輸出 JSON：`{"emoji": "名稱" 或 ""}`。程式驗證名稱在圖鑑裡，不在就當不配；一則最多一個（表情或貼圖二選一）。
   - prompt 描述怎麼挑：依「她這句回話的語氣」＋原訊息；不確定就不配；**微笑類可以配在嘲諷、反諷的回話上**（D-33 的群組用法）。不放範例句。
   - 只在有 reviewed 圖鑑、`EmojiPacing.allow` 的時候挑；**語音回覆不挑**（`spoken`／語音路徑完全不呼叫）。插話的回話也走同一步。
   - 追蹤紀錄：記選了什麼、花多久、超時／出錯原因。
3. `bot.py` 送出那段：回話＋挑到的表情一起送；`EmojiPacing.record` 照用到沒用到記。對話紀錄裡她那則照實際送出的內容記。
4. **文件**：開發規格 6.14 第 2 節改成「先回話、再依回話挑表情」；第 3 節註明 B2 按反應維持現狀、D-33 的做法不上線。

## 評估
- **挑表情評估**（改 `scripts/eval_emoji.py` 或新增模式）：題目＝「原訊息＋她的回話」，選哪張或不選。題目從現有 eval_emoji 的情境產生回話後再挑，或直接用正式回覆流程產生；用主伺服器圖鑑（`data/emoji/<主伺服器ID>.json`）。至少 50 題，含嘲諷／反諷回話、一般附和、認真回答、被嘴回嘴幾類。
  - 報：配的比例（目標 10%～30%）、壞名稱 0、一則超過一個 0、挑表情多花的秒數。
  - 模型評分合不合適：評分規則加一條「**微笑類配嘲諷、反諷的回話算合適**」。跑兩次（D-21）。
- **使用者自評檢查頁**：`data/emoji/D37-檢查.html`（`data/` 不進 repo）。一題一列：原訊息、她的回話、選的表情圖（用圖鑑裡的圖片網址顯示圖；沒選就寫「不配」）、「合適／不合適」兩個按鈕。結果存在瀏覽器 localStorage，並有「匯出結果」按鈕（下載 JSON 或顯示可複製的文字），讓 PM 拿回來算。說話者用佔位名。最後以使用者評的為準，模型評分只當參考。
- **插話判斷不能退步**：66 題只測插話（不帶 `--route`）跑兩次，≥ 78.8%（插話 prompt 沒改，應該不變）。
- **回覆沒變差**：R2 小評估（`data/eval_r2/`）跑兩次，壞掉比例、開頭重複、D-36 髒話不能比 R3 差（回覆 prompt 拿掉表情清單後確認）。

## 測試（`..\.venv\Scripts\python.exe -m pytest -q` 全過）
- 挑表情：名稱在圖鑑 → 用；不在／空 → 不配；JSON 壞掉 → 不配；超時 → 不配、照送。
- 語音回覆不呼叫挑表情；沒有圖鑑、pacing 不允許時不呼叫。
- 回覆 system 不含表情清單。
- 送出時表情接在回話後、貼圖用 `stickers=`。
