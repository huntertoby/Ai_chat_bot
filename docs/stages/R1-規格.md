## 第 1 段：隱私規則與行為 bug（先做）
1. **拿掉「不准拿成員名字上網查」**（改到使用者定過的規則）：

   - `yuki/prompts.py` 叫她不要上網查成員的段落（約 87／125／146 行附近）；B4 的 `BACKGROUND_RULES` 裡「成員只查封存區、絕不上網」改成：成員的事先查封存區，需要時也可以上網。不放範例句。
   - `開發規格.md` 6.13（約 600、608 行）和「熱門話題預先查」的「不是成員名字」條件照 D-27 改。
   - **保守保留**：打過 `/不要記我` 的人，名字不拿去搜（`web_search` 和 `open_url` 的網址都要擋）。報告列出來讓使用者確認。
2. **`/不要記我` 以人為單位**（審查一-3）：退出名單跨伺服器；刪資料時所有伺服器的封存、人物檔案、記憶都刪；借主伺服器資料（測試伺服器、私訊）前先查退出名單；把 `skip_authors` 接上。
3. **行為 bug**（審查一-4、一-6、一-7）：
   - 結束字：只在跟她講話時看、整句比對（不是子字串）、先記進對話紀錄再 return。
   - `_replying` 計數移進 try（例外不會讓計數卡住）。
   - 喚醒詞加字邊界。
   - 主伺服器注意模式走熱鬧模式；回覆時不再延長注意時間（使用者已同意這項主伺服器行為改動）。
   - `/忘記` 不重述要刪的內容；`/記憶` 只有本人看得到（ephemeral）。
   - `scripts/check_private.py`：掃這次 push 的每個 commit（`@{u}..HEAD` 或 hook 給的範圍），不只 HEAD。
   - 設定預設值改成跟正式環境一致（看 `.env` 有設、預設不同的；只改預設值，不改 `.env`；`.env` 的值不能進 repo）。
4. **LLM 排隊**（審查一-5）：聊天優先；背景人物檔案整理不能卡住聊天（例如背景請求只在沒人等時才送、或有獨立的低優先排隊；背景的單次逾時不能讓聊天等超過幾秒）。加測試。
