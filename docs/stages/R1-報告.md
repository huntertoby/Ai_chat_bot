### 4. LLM 排隊聊天優先（審查一-5）— `eeb20f0`
- `yuki/llm.py` 新增 `LLMSlots` 取代共用的 semaphore：聊天（回覆、插話判斷）先排；背景（人物檔案整理）只在沒有聊天在等時才送；**聊天要等時，正在跑的背景請求直接中斷讓位**（關掉連線，背景那邊拿到 `LLMError(PREEMPTED)`，進度不推進，下次閒置從同一段重做）。所以背景的單次逾時（600 秒）不會再讓聊天等。
