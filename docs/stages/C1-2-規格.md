# C1 第二步：回覆、按反應用群組表情與貼圖 — 規格

> 對應：`開發規格.md` 6.14 第 1 點後半、第 2～4 點。D-26：做完照常上線到**測試伺服器**；主伺服器不動。
> 前提：C1 第一步的圖鑑（`data/emoji/<伺服器ID>.json`，`yuki/emoji_catalog.py`）。6.14 寫「你看過 meaning 準不準再開放給她用」，所以**程式先上線，但圖鑑沒被使用者確認前不會用**（見第 1 點）。

## 1. 載入圖鑑（`yuki/emoji_catalog.py` 加讀取用的部分；Yuki 本體開始 import）
- 啟動時讀 `data/emoji/*.json`。圖鑑檔加一個最上層欄位 `reviewed`（使用者看完 C1-1 的檢查頁後由開發 PM 改成 true；建圖鑑時預設 false，重跑保留原值）。**`reviewed` 不是 true 的圖鑑整份不用**。
- 只用 `use=true`、有 `meaning` 或 `looks` 的。
- 測試伺服器借主伺服器的圖鑑時（`PROFILE_FALLBACK_GUILD`）：**只能發 Yuki 所在那個伺服器自己的表情**。測試伺服器沒有自己的圖鑑就不用表情（6.14：別的伺服器的人看了沒意義）。測試伺服器要測，就對測試伺服器也跑一次 `build_emoji_catalog --guild <測試伺服器>`。
- 啟動時比對 `guild.emojis`：圖鑑裡有、伺服器已刪的不用；伺服器新增或改名的記在 log（自動補建等之後再做，這次不做）。

## 2. 回覆時用（`yuki/prompts.py`、`yuki/brain.py` 或回覆後處理）
- reply system 加一段：那個伺服器 `use=true` 裡最常用的 20～30 張，每行 `:名稱: 什麼情況用`（沒有 meaning 就用 looks）。名稱太難念（非中英數、太長）就給別名，程式記對照。
- 人設「少用表情符號和 XD」改成描述「偶爾用群組的貼圖代替一般表情符號，不要每句都用」的意思（**不放範例句**）。
- 程式後處理：`:名稱:` → `<:名稱:ID>`（動圖 `<a:名稱:ID>`）；不在清單裡的 `:xxx:` 刪掉；**一則最多 1 個**群組表情或 1 張貼圖，多的刪掉。
- 貼圖：模型在最後寫 `[貼圖:名稱]` → 程式拿掉這段，用 `stickers=` 另外附上（一則最多一張；跟表情合計最多 1 個）。
- 沒有圖鑑（或沒 reviewed）的伺服器：這段 prompt 不放，後處理照樣把 `:xxx:`、`[貼圖:…]` 清掉。

## 3. 按反應（`yuki/chime.py`、`yuki/bot.py`）
- B2 已經有 `action=react`＋`emoji`。插話判斷的 prompt 加最常用的 **10 張**（名稱＋一句用途）讓模型選；`emoji` 可以是那些名稱或 unicode。找不到就不按（現況）。
- 插話判斷速度要維持 ≤ 0.6 秒（中位數），加了清單變慢就減張數。
- 被叫到時「回一句＋在原訊息按反應」：這次**不做**（會讓每次被叫都多一次判斷），報告列為之後再看。

## 4. 語音
- `speakable()` 念出來前刪掉 `<:名稱:ID>`、`<a:名稱:ID>`、`:名稱:`、`[貼圖:…]`。

## 驗收（照 6.14）
- 評估腳本 `scripts/eval_emoji.py`（不需要 Discord）：
  - 回覆：50 則回覆（真實對話片段當前文）用到表情的 10%～30%；沒有壞掉的 `:名稱:`；沒有一則用兩個以上。
  - 反應：20 則「值得理一下」的訊息（從 `data/eval_b/chime_cases` 或封存區挑，放 `data/eval_c1/`），選 react 而且表情合適 ≥ 70%（合適由 LLM 依 meaning 判，抽 5 則人工看）。
  - 語音：念出來的文字沒有 `<:`。
- 改了回覆 prompt：既有的閒聊 30 句跑兩次，跟 B 階段比不退步（D-21）。
- 插話 50 題跑兩次，正確率不低於 78%、速度 ≤ 0.6 秒。
- 單元測試：替換、刪壞名、一則上限、貼圖抽出、reviewed=false 不用、跨伺服器不用、speakable。

## 上線
- 測完照 D-26：停 Yuki 測試後跑 `scripts/autostart/start.ps1` 還原，看 `logs/yuki.log` 確認上線。只在測試伺服器測。

## 不做
- 自動補建新表情、被叫時同時按反應。
- 主伺服器用表情：用 `EMOJI_GUILD_IDS` 控制（留空＝只有 `TEST_GUILD_IDS`），所以主伺服器的圖鑑 reviewed 之後也不會自動在主伺服器用，要另外決定。
