## 第 4 項：按反應重測（新圖鑑）

### 結論：**不上線**
- 正式 prompt（`yuki/prompts.py`）和 `CHIME_EMOJI_LIST=0` 預設**都沒動**。
- 三條上線標準一條都沒過：
  - 按反應合適：人工判嚴格 **30%**、寬鬆 **55～60%**（標準 70%）；評分員也只給 55%。
  - 帶清單插話：最好的變體 E2 是 **74.2%**（標準 78.8%，差 3 題）。
  - talk_to_me：E2 是 **16/17**（標準全對），代名詞題 9/9 有達到。
- 新圖鑑有一個副作用：說明加了「嘲諷、被吐槽時裝無辜」之後，**現行 prompt 帶清單也從 76% 掉到 69.7%**，代名詞題 6/9。模型看到「被吐槽／被嘴」就去按那張「被吐槽時抿嘴微笑」的表情，不開口回。

### 跑了什麼
- 圖鑑：主伺服器新圖鑑（`data/emoji/<主伺服器ID>.json`，reviewed=true），清單放最常用 10 張。
- 三組 prompt，每組兩次（D-21）：
  - **現行**：`yuki/prompts.py` 原樣。
  - **E1**：實驗 4 的變體，照搬到 D-29 之後的 prompt。改了三件事：
    - emoji 欄的說法統一。
    - 加 `feeling` 欄（放在 emoji 前面，最多 12 字）。
    - 先寫這則讓人有什麼反應，再對表情的用法說明。
    - schema 順序跟著現在的順序：kind → action → participate → feeling → emoji → reason → need_background。
  - **E2**：E1 再小改兩處，沒有範例句：
    - (1) 通用型的說法加上「萬用」，因為新圖鑑兩張頭像寫的是萬用。
    - (2) 表情段加一條：在跟你講話、問你、質疑你、叫你做事，或有人嘲笑、挑釁你時要開口，不能用按表情代替。
- 按反應：`eval_emoji --only react`（20 題 `react_cases.jsonl`）。插話：`eval_chime --only chime --emoji <新圖鑑>`（66 題，不帶 `--route`，跟 D-32 的 78.8% 同一種跑法）。
- 中間檔（不進 repo）：`data/eval_c1/d33/`（`variant_e1.py`、`variant_e2.py`、`run_emoji.py`、`run_chime.py`、`summarize.py`、`results/`）。
- **速度有雜訊**：LM Studio 同時在服務 Yuki，一次只處理一個請求，秒數只能拿來比相對快慢。

### 下一步選項（給 PM／使用者決定）
1. **維持現狀**（建議先這樣）：插話不帶清單，按反應只按一般表情。插話 78.8% 不受影響。
2. **把按表情從插話判斷拆出來**（C1-2 的選項 b）：
   - 做法：插話判斷照舊不帶清單；只在結果是 none（或 react）時，另外跑一次只挑表情的小判斷（E1 的 feeling → 對說明，不用判斷要不要開口）。
   - 好處：插話正確率不會被拖下來，「被吐槽裝無辜」那張也不會把該回的訊息搶走。
   - 代價：多一次 LLM 呼叫，約 0.7 秒，佔 LM Studio。可以只在有人笑／抱怨的跡象，或頻道按表情額度還有時才跑。
   - 但光拆開不夠，因為按表情本身人工只有 30～60%。還要加上第 3 點。
3. **改圖鑑的說明或清單**（要使用者決定）：
   - e4 的「表示已讀」讓它變成萬用牌，可以考慮拿出按反應清單，或把說明寫窄。
   - 「被吐槽時抿嘴微笑裝無辜」那張在插話判斷裡會搶走該開口的題，如果要帶清單，最好不要放進插話用的清單。
   - 紅溫、驚訝、瞪眼這幾張說明寫得很具體，但一次都沒被選到，可能是排在清單後面，或說明太長。
4. **程式端保底**（小改，不靠 prompt）：
   - kind 是 to_me 而 action 是 react 時，改成照 participate 走 reply。
   - 這次「現行＋清單」錯的 to_me 4 題（03、06、10、12）大概能救回 3 題（06 的 participate 只有 0.2 救不到）。about_me 的嘲諷題救不到。
   - 這是行為規則的改動，要 PM 決定。
5. 題目本身：react 20 題有幾題標籤怪（#1 標「里程碑」，但模型和評分員都當成抽卡歪；#2 也標「里程碑」）。20 題、1 題就是 5 個百分點，人工判的嚴格／寬鬆差很大，建議擴題、而且先人工標好「該按哪幾張」，再談 70% 的標準。

### 沒把握的地方

- 有幾則訊息的意思我不確定（#1 的注音縮寫、#7 是不是在講機率低），判斷可能有誤，各影響 1 題。
